DOCTOR USER STORY
1.As a doctor, I want to view a patient's complete medical history and past visit notes before an appointment so that I can make informed diagnostic decisions.
2.As a doctor, I want to create and send digital prescriptions directly to the patient's account so that I can eliminate paper-based errors and save time.
3.As a doctor, I want to set and modify my available working hours and block out personal time so that my daily schedule avoids double-bookings.

PATIENT USER STORY
1.As a patient, I want to view and download my current and past prescriptions from my dashboard so that I can easily buy medications or reference past treatments.
2.As a patient, I want to access my lab results and consultation summaries online so that I can track my overall health progress.
3.As a patient, I want to view available doctor time slots and book an appointment online so that I can schedule visits without calling the clinic.

ADMIN USER STORY
1.As a admin, I want to add, edit, or deactivate doctor, staff, and patient profiles so that only authorized users can access the clinic system.
2.As a admin, I want to generate daily appointment reports and track doctor visits so that I can monitor clinic efficiency and manage staff workloads.
3.As a admin, I want to generate invoices for completed appointments and record payments so that the clinic's financial records are accurate.
